# CUMCM 数学建模工具箱

## 1. 项目简介

本项目是面向全国大学生数学建模竞赛（CUMCM）的个人算法工具库，主要供团队中的代码负责同学在比赛期间快速选择、调用和改造模型。

这不是一个自动完成建模的框架。各文件提供相对独立的算法封装或基础函数，覆盖从数据处理到结果验证的主要环节：

```text
原始数据
  ↓
清洗、标准化、相关分析与可视化
  ↓
预测 / 优化 / 综合评价 / 机器学习 / 数值计算
  ↓
误差分析、模型比较、敏感性分析与结果展示
```

使用时应先根据题目目标和数据特点选择模型，再完成数据划分、参数设置、结果检验和论文解释。工具箱中的模型不能替代这些建模判断。

> 当前代码以单文件模板为主，没有统一的包入口。目录名以数字开头，不能直接写成常规的 `from 01_Data_Analysis...` 导入语句。最直接的使用方式是在对应目录中编写脚本，或将该目录加入 `sys.path` 后导入文件中的类或函数。

# 模块 1：`01_Data_Analysis` 数据分析与预处理

### 模块作用

用于建模开始前的数据质量检查、尺度统一、变量关系探索和基础绘图。它能帮助判断数据是否需要填补、是否存在重复、各指标是否量纲一致，以及变量之间是否存在明显关系。

### 包含方法

| 方法/文件 | 主要作用 | 解决的问题 | 典型使用场景 |
|---|---|---|---|
| `check_missing` | 统计每列缺失值 | 数据完整性检查 | 导入数据后首先检查 |
| `fill_missing` | 均值或中位数填充 | 数值列存在空值 | 少量随机缺失的快速处理 |
| `remove_duplicates` | 删除重复行 | 重复观测 | 数据清洗 |
| `describe_data` | 描述性统计 | 了解量级与分布 | 建模前的数据概览 |
| `min_max_normalize` | 缩放到 `[0,1]` | 指标量纲不同 | 综合评价、距离模型 |
| `z_score_normalize` | 零均值、单位标准差 | 特征尺度差异 | SVM、聚类、PCA 前处理 |
| `positive_negative_normalize` | 统一评价指标方向 | “越大越好”和“越小越好”混合 | 综合评价预处理 |
| `pearson_correlation` | Pearson 系数矩阵 | 线性相关性 | 连续变量关系初筛 |
| `spearman_correlation` | Spearman 系数矩阵 | 秩单调相关性 | 非正态或有异常值的数据 |
| 六个绘图函数 | 分布、关系、相关和预测图 | 快速探索和展示 | 数据分析与论文配图初稿 |

### 文件说明

| 文件 | 功能 | 输入 | 输出 | 什么时候调用 |
|---|---|---|---|---|
| `correlation.py` | 调用 Pandas 计算 Pearson/Spearman 矩阵 | 数值型 `DataFrame` | 相关系数 `DataFrame` | 筛查变量关系或绘制相关热力图前 |
| `data_clean.py` | 缺失检查、填补、去重、描述统计 | `DataFrame`；填补方法为 `mean` 或 `median` | Series 或新 `DataFrame` | 原始数据进入模型前 |
| `data_read.py` | 实际内容与 `data_clean.py` 相同 | `DataFrame` | Series 或 `DataFrame` | 当前不能用于读取 CSV/Excel，建议不要按文件名调用 |
| `normalization.py` | 三种标准化方式 | 数值 `DataFrame`；正负指标列名 | 新 `DataFrame` | 量纲影响距离、权重或模型训练时 |
| `visualization.py` | 直方图、箱线图、散点图、折线图、热力图、预测对比图 | DataFrame、数组或序列 | 无返回值，直接显示图形 | 探索数据或快速检查结果时 |

### 优势与局限

优势：接口简单，直接接收 Pandas/数组数据；覆盖比赛中最常见的清洗、标准化和基础图表。

局限：没有真实的数据读取函数；均值和中位数只填充数值列；相关分析没有显著性检验；标准化没有处理常数列；sklearn 标准化结果会丢失原索引；绘图函数直接调用 `show()`，不返回 Figure/Axes。

# 模块 2：`02_Prediction` 预测模型

### 模块作用

用于预测未来序列值或根据特征预测连续目标。选择模型时应区分“只有时间轴的一维序列”和“有多个解释变量的监督回归”。

### 包含方法

| 方法/文件 | 主要作用 | 解决的问题 | 典型使用场景 |
|---|---|---|---|
| ARIMA | 单变量时间序列外推 | 自相关、差分后平稳的序列 | 给定历史序列预测未来若干期 |
| GM(1,1) | 灰色序列建模 | 理论上面向少数据趋势序列 | 当前实现需修正，不作为正式结果工具 |
| 线性回归 | 线性监督回归 | 多特征与连续目标近似线性 | 基准模型、解释清晰的预测 |
| 多项式回归 | 低阶非线性回归 | 特征与目标存在曲线关系 | 单变量或低维曲线趋势 |
| 随机森林回归 | 树集成回归 | 非线性和特征交互 | 中小规模表格数据 |
| XGBoost 回归 | 梯度提升树回归 | 复杂非线性表格预测 | 需要更强表格基线时 |
| LSTM | 序列网络结构 | 时序或序列映射 | 已自行准备窗口、训练循环时 |

### 文件说明

| 文件 | 功能 | 输入 | 输出 | 什么时候调用 |
|---|---|---|---|---|
| `ARIMA.py` | `ARIMAModel(order)` 封装 statsmodels ARIMA | `fit(data)` 为一维序列；`predict(steps)` 为步数 | 未来预测序列；`summary()` 返回模型摘要 | 序列可以通过差分处理且无明显季节模型需求时 |
| `GreyPrediction.py` | 手写 GM(1,1) 参数估计和指数响应 | 一维数值序列、预测点数 | NumPy 数组 | 仅供代码研究；当前不建议直接用于正式预测 |
| `LinearRegression.py` | sklearn 线性回归 | 二维 `X`、连续 `y` | 预测数组；MSE、R² 字典 | 需要线性基线或较强可解释性时 |
| `PolynomialRegression.py` | 多项式特征后做线性回归 | 二维 `X`、连续 `y` | 预测数组；MSE、R² 字典 | 关系弯曲但可用低阶多项式描述时 |
| `RandomForest.py` | 随机森林回归 | `X`、连续 `y` | 预测、MSE/R²、特征重要性 | 非线性表格数据且不要求函数形式时 |
| `XGBoost.py` | XGBoost 回归 | `X`、连续 `y` | 预测、MSE/R²、特征重要性 | 表格数据预测并愿意进一步调参时 |
| `LSTM.py` | PyTorch LSTM 加线性输出层 | `[batch, sequence, input_size]` Tensor | `[batch, 1]` Tensor | 已有完整 PyTorch 训练代码，只需要网络结构时 |

### 优势与局限

- ARIMA 接口简洁并能输出 statsmodels 摘要，但不自动做平稳性检验、定阶、季节建模、残差诊断或滚动验证。
- 线性和多项式回归易于建立基线，但代码没有显著性检验、多重共线性诊断或正则化。
- 随机森林和 XGBoost 能处理非线性及交互关系，并提供特征重要性；但代码不含训练/测试划分、交叉验证或参数搜索。
- 所有 `evaluate()` 都在调用者传入的数据上计算结果。若传入训练集，得到的是训练误差，不代表泛化能力。
- LSTM 只有 `forward()`，没有窗口构造、归一化、损失函数、优化器、训练、预测和评估流程。
- 当前 GM(1,1) 没有保存首个原始观测值，响应公式使用常数 `1`，且未通过相邻累减还原原序列，因此不应直接视作完整 GM(1,1) 预测实现。

# 模块 3：`03_Optimization` 优化与规划

### 模块作用

用于在约束条件下寻找最优决策。若目标和约束都是线性的，优先使用规划模型；结构难以表达、目标函数像黑箱时，再考虑遗传算法或模拟退火。

### 包含方法

| 方法/文件 | 主要作用 | 解决的问题 | 典型使用场景 |
|---|---|---|---|
| 线性规划 | 连续变量精确优化 | 线性资源分配 | 生产、运输、配比 |
| 整数规划 | 非负整数决策 | 数量不能为小数 | 设备数、人员数、批次数 |
| 0-1 规划 | 二元选择决策 | 选择/不选择 | 选址、项目组合 |
| 非线性优化 | SLSQP 局部最小化 | 光滑非线性目标和约束 | 参数设计、连续配比 |
| 遗传算法 | 种群式随机最大化 | 黑箱连续优化 | 非凸、多峰目标的近似搜索 |
| 模拟退火 | 单解随机最大化 | 黑箱连续优化 | 允许一定概率接受较差解的搜索 |

### 文件说明

| 文件 | 功能 | 输入 | 输出 | 什么时候调用 |
|---|---|---|---|---|
| `LinearProgramming.py` | SciPy HiGHS 线性规划 | 目标系数 `c`、`A`、`b`、是否最大化 | 成功返回 `{"x", "value"}`，失败返回 `None` | 非负连续变量且约束均可写为 `A x <= b` |
| `IntegerProgramming.py` | PuLP/CBC 整数规划 | `c`、`A`、`b`、是否最大化 | 决策值和目标值字典 | 非负整数变量和 `<=` 约束 |
| `ZeroOneProgramming.py` | PuLP/CBC 二元规划 | `c`、`A`、`b`、是否最大化 | 0/1 方案和目标值 | 项目选择、设施启用等二元决策 |
| `NonlinearOptimization.py` | SciPy SLSQP 最小化 | 目标函数、初值、边界、约束 | 成功返回解和目标值，否则 `None` | 目标可计算、约束可传给 SLSQP 时 |
| `GeneticAlgorithm.py` | 初始化、选择、单点交叉、随机重置变异 | 适应度函数、连续变量边界等 | 最后一代中适应度最大的变量向量 | 目标复杂且只求近似最大值时 |
| `SimulatedAnnealing.py` | 随机初值、单变量重采样邻域、退火接受 | 目标函数、边界、温度、降温率、迭代数 | `{"x", "value"}` | 黑箱连续变量最大化，维度不太高时 |

### 优势与局限

- 三种规划工具结构明确，适合能准确写出目标和约束的问题；但线性规划只支持非负变量和 `<=` 约束，整数/0-1 规划也没有等式或 `>=` 接口。
- 整数与 0-1 规划没有检查求解状态，不可行时仍可能尝试读取结果。
- 非线性优化固定为 SLSQP 最小化，最大化需自行对目标取负；它是局部方法，结果依赖初值。
- 遗传算法和模拟退火均固定为最大化，没有通用约束处理、收敛曲线或随机种子接口。
- 遗传算法只返回解、不返回适应度，并且只保留最终一代最优，不保证保存全程最优；单变量问题还会因交叉点范围无效而失败。
- 模拟退火的邻域是随机重置一个变量，不是局部微扰，问题相关的邻域结构需自行改造。

# 模块 4：`04_Evaluation` 综合评价

### 模块作用

用于“多个方案、多个指标”的赋权、评分和排序。常见组合是：先统一指标方向，再用 AHP 或熵权法确定权重，最后用 TOPSIS 排序；模糊综合评价则适合已建立等级隶属度矩阵的问题。

### 包含方法

| 方法/文件 | 主要作用 | 解决的问题 | 典型使用场景 |
|---|---|---|---|
| AHP | 主观赋权和一致性检验 | 专家判断如何转为指标权重 | 层次清晰、可构造两两比较矩阵 |
| 熵权法 | 根据数据差异客观赋权 | 减少纯主观赋权 | 多方案、多指标评价 |
| TOPSIS | 与正负理想方案比较 | 综合得分和优劣排序 | 方案评价、地区排名 |
| 模糊综合评价 | 权重与隶属度合成 | 定性等级的综合判定 | 风险等级、质量等级 |

### 文件说明

| 文件 | 功能 | 输入 | 输出 | 什么时候调用 |
|---|---|---|---|---|
| `AHP.py` | 特征向量法求权重；计算 CI/RI | 正判断矩阵；一致性函数还接收权重 | 权重向量、CR | 已有专家两两比较结果时 |
| `EntropyWeight.py` | 极差标准化后计算熵权 | 样本 × 指标矩阵 | 每项指标的权重数组 | 希望按样本差异程度客观赋权时 |
| `FuzzyEvaluation.py` | `weights @ relation_matrix`；最大隶属度判级 | 权重、隶属度矩阵、等级列表 | 综合隶属度向量或等级 | 已经建立评价集和隶属度时 |
| `TOPSIS.py` | 向量标准化、加权、理想解距离 | 评价矩阵、正负指标列表、可选权重 | 每个方案的贴近度得分 | 需要对多个方案综合排序时 |

### 优势与局限

- AHP 能表达专家偏好，但代码不校验矩阵的方阵性、正性和互反性；RI 只覆盖 1～9 阶，1～2 阶会出现除零问题。
- 熵权法由数据决定权重，但差异大不等于业务上更重要；代码默认所有指标正向，常数列和单样本会造成除零。
- TOPSIS 结构直观，可组合主观或客观权重；但只处理正向/负向两类指标，零向量列、权重不合法或理想距离同时为零时没有保护，且只返回得分不直接排序。
- 模糊综合评价代码简洁，但需要外部先构造可靠的隶属度矩阵；代码不校验权重和行隶属度是否合法，只按最大隶属度返回等级。

# 模块 5：`05_Machine_Learning` 分类、聚类与降维

### 模块作用

用于有标签分类、无标签分组和高维特征压缩。回归类机器学习模型位于 `02_Prediction`。

### 包含方法

| 方法/文件 | 主要作用 | 解决的问题 | 典型使用场景 |
|---|---|---|---|
| 决策树 | 分类和特征重要性 | 有标签类别预测 | 需要规则型、较直观的分类基线 |
| SVM | 标准化后的核分类 | 中小样本分类 | 类别边界可能非线性 |
| K-Means | 标准化后聚类 | 无标签样本分组 | 客户、地区、状态分类 |
| PCA | 标准化后降维 | 高维和相关指标压缩 | 可视化、综合指标或建模前降维 |

### 文件说明

| 文件 | 功能 | 输入 | 输出 | 什么时候调用 |
|---|---|---|---|---|
| `DecisionTree.py` | sklearn 决策树分类 | `X`、类别标签 `y` | 类别、准确率、特征重要性 | 需要容易解释的分类基线时 |
| `SVM.py` | StandardScaler + SVC | `X`、类别标签 `y` | 类别和准确率 | 特征量纲不同、样本规模适中时 |
| `KMeans.py` | StandardScaler + KMeans | 无标签 `X` | 聚类标签、标准化空间中心 | 已确定聚类数并希望按相似性分组时 |
| `PCA.py` | StandardScaler + PCA | 高维特征矩阵 | 主成分矩阵、解释方差比例 | 指标相关或维度较高时 |

### 优势与局限

- 决策树可给出特征重要性，但当前没有树结构导出、剪枝选择或准确率以外的分类指标。
- SVM 自动保持训练集的标准化器并用于预测，适合量纲不同的数据；虽然设置 `probability=True`，类中却没有暴露概率预测接口。
- K-Means 自动标准化，但聚类数必须人工指定；没有肘部法或轮廓系数，返回的中心也处于标准化空间。
- PCA 自动标准化并返回解释方差比例，但不提供主成分载荷接口。
- 所有监督模型都要求调用者自行划分训练集和测试集；没有交叉验证和参数搜索。

# 模块 6：`06_Numerical_Methods` 数值方法

### 模块作用

用于求解有明确数学结构的问题，包括函数拟合、动态系统、插值、频率分析、随机估计和数值积分。

### 包含方法

| 方法/文件 | 主要作用 | 解决的问题 | 典型使用场景 |
|---|---|---|---|
| Curve Fitting | 拟合自定义函数参数 | 已知函数形式、参数未知 | 机理参数估计、经验曲线 |
| ODE | 求解常微分方程初值问题 | 状态随时间连续变化 | 种群、传播、运动、反应过程 |
| FFT | 时域转频域、寻找主频 | 周期结构 | 振动、周期需求、信号分析 |
| Interpolation | 线性/三次插值 | 离散点间补值 | 稀疏测量数据连续化 |
| Monte Carlo | 随机估计 π 和定积分 | 随机模拟与采样积分 | 复杂问题原型、随机实验 |
| Numerical Integration | 三种数值积分 | 函数或离散点求积 | 累计量、面积、期望计算 |

### 文件说明

| 文件 | 功能 | 输入 | 输出 | 什么时候调用 |
|---|---|---|---|---|
| `CurveFitting.py` | SciPy `curve_fit` 非线性最小二乘 | 自定义 `model_func`、`x`、`y`、可选 `p0` | 参数保存在对象中；`predict(x)` 返回拟合值 | 已知函数形式并需要估计参数时 |
| `DifferentialEquation.py` | SciPy `solve_ivp` | `dy/dt=f(t,y)`、`t_span`、`y0`、可选 `t_eval` | `{"t", "y"}` | 建立连续时间动态模型后求数值解 |
| `FFT.py` | NumPy FFT 和主频搜索 | 一维信号、采样率 | 完整频率数组、幅值数组或一个主频 | 寻找周期线索时 |
| `Interpolation.py` | SciPy `interp1d` | 已知坐标 `x, y` | 可调用的线性或三次插值函数 | 需要估计已知区间内部数据时 |
| `MonteCarlo.py` | 均匀随机采样 | 样本数；积分函数和区间 | π 或积分估计值 | 可用随机样本均值表达目标时 |
| `NumericalIntegration.py` | 梯形、Simpson、自适应求积 | 离散 `x,y` 或函数和区间 | 积分标量 | 问题确定且需要数值求积时 |

### 优势与局限

- 曲线拟合支持任意可调用函数，但只保存参数，不返回协方差、拟合优度或置信区间。
- ODE 封装简洁，但没有暴露算法、容差、事件等配置，也没有返回求解状态。
- FFT 返回未经归一化的双边频谱，没有去均值、加窗和单边幅值修正；主频搜索可能返回负频率，适合快速探索而非严格频谱测量。
- 插值默认不外推，三次插值需要足够且合法的已知点；代码不预检排序和重复坐标。
- 蒙特卡洛没有随机种子、方差、误差或置信区间；积分函数应支持 NumPy 数组输入。
- Simpson 固定使用 100 个采样点；自适应积分只返回积分值，丢弃 SciPy 给出的误差估计。

# 模块 7：`07_Modeling_Tools` 模型验证与结果表达

### 模块作用

用于模型完成后的评价、比较、敏感性检验和绘图。该模块不负责替代训练或求解过程，而是接收已经得到的真实值、预测值、指标或模型函数。

### 包含方法

| 方法/文件 | 主要作用 | 解决的问题 | 典型使用场景 |
|---|---|---|---|
| ErrorAnalysis | 五种回归误差 | 预测结果是否准确 | 测试集预测后 |
| ModelComparison | 汇总和单指标排序 | 多模型横向比较 | 比较 ARIMA、回归、树模型等 |
| SensitivityAnalysis | 单因素局部敏感度和范围扫描 | 参数变化是否显著影响结果 | 稳健性分析 |
| Visualization | 四类结果图 | 展示趋势、关系和预测 | 结果检查和论文图表初稿 |
| GreyRelation | 当前未实现 | 暂不能解决灰色关联问题 | 不应调用 |

### 文件说明

| 文件 | 功能 | 输入 | 输出 | 什么时候调用 |
|---|---|---|---|---|
| `ErrorAnalysis.py` | 手写 MAE、MSE、RMSE、MAPE、R² | 等长真实值和预测值 | 单项标量或完整指标字典 | 在独立验证集/测试集得到预测后 |
| `GreyRelation.py` | 空文件 | 无 | 无 | 当前不能调用 |
| `ModelComparison.py` | 添加模型指标、转 DataFrame、按指标排序 | 模型名、指标字典、排序指标和方向 | 结果表或排序表 | 各模型已完成评估后 |
| `SensitivityAnalysis.py` | 单参数相对扰动和指定范围扫描 | 模型函数、参数、参数位置、变化量/取值 | 敏感度或模型输出列表 | 检查关键参数对结果的影响时 |
| `Visualization.py` | 折线、散点、热力图、预测对比图 | 数组或矩阵 | 无返回值，直接显示 | 模型结果快速可视化时 |

### 优势与局限

- `ErrorAnalysis` 能统一常用回归指标，但真实值含 0 时 MAPE 会除零，真实值完全相同时 R² 会除零，也没有形状校验。
- `ModelComparison` 适合快速生成论文对比表，但只汇总外部传入的指标，不运行模型、不校验指标一致性，也不做多指标综合排名。
- `SensitivityAnalysis` 容易调用，但只考虑单因素；基准输出为 0 时局部敏感度会除零，也不分析参数交互。
- `Visualization.py` 与数据分析模块的绘图功能部分重复，同样直接 `show()`，不返回 Figure/Axes。
- `GreyRelation.py` 当前为空，所以本项目目前不具备灰色关联分析功能。

## 5. 常见建模流程

### 5.1 预测问题

```text
检查缺失和重复
  → 查看分布与时间趋势
  → 根据数据结构选择 ARIMA / 回归 / 树模型
  → 自行划分训练集和测试集
  → 训练并预测
  → ErrorAnalysis 计算误差
  → ModelComparison 比较候选模型
  → 绘制真实值与预测值对比
```

选择原则：

- 只有时间序列且关注自相关：先考虑 ARIMA；
- 有解释变量且关系近似线性：线性回归；
- 有解释变量且关系弯曲：低阶多项式或自定义曲线拟合；
- 表格特征关系复杂：随机森林或 XGBoost；
- LSTM 当前只提供网络结构，不是开箱即用的预测流程。

### 5.2 综合评价问题

```text
确定方案和指标矩阵
  → 处理指标正负方向
  → AHP 或熵权法确定权重
  → TOPSIS 计算方案得分
  → 按得分排序并做敏感性分析
```

若题目本身采用“优秀、良好、一般、较差”等等级体系，并且可以构造隶属度矩阵，可改用模糊综合评价。

### 5.3 优化决策问题

```text
明确决策变量、目标函数和约束
  → 判断是否线性
  → 判断变量是连续、整数还是 0-1
  → 优先选择对应规划方法
  → 难以写成规则规划时再考虑启发式算法
  → 检查可行性、约束满足情况和结果稳定性
```

优先级建议：

1. 连续线性问题：线性规划；
2. 整数数量问题：整数规划；
3. 选择问题：0-1 规划；
4. 光滑非线性问题：SLSQP；
5. 黑箱或多峰问题：遗传算法、模拟退火。

### 5.4 机理与数值问题

```text
写出函数或动态方程
  → 选择曲线拟合 / ODE / 插值 / 积分
  → 检查数值解和边界条件
  → 对关键参数做敏感性分析
  → 绘制结果
```

## 6. 调用注意事项

### 6.1 结果解释

- 不要只报告模型在训练数据上的指标；
- 启发式算法应多次运行并比较稳定性；
- 综合评价结果应检查权重变化是否影响排序；
- 任何自动计算结果都要回到题目约束和现实含义检查；
- 特征重要性表示模型使用特征的程度，不直接等同于因果影响。

### 6.2 当前尚未提供的功能

- CSV、Excel 数据读取封装；
- 灰色关联分析；
- 完整可靠的 GM(1,1) 预测流程；
- LSTM 数据准备、训练和评估流程；
- 自动训练/验证划分与交叉验证；
- 自动超参数搜索；
- 模型保存和加载；
- 依赖版本文件和自动化测试。

README 中不将以上内容视为已经实现的能力。
