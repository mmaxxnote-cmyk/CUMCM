# CUMCM 数学建模工具箱

## 1. 项目简介

本项目是面向全国大学生数学建模竞赛（CUMCM）的个人算法工具库，帮助代码负责同学快速完成模型选择、代码定位和结果验证。

工具箱覆盖以下建模流程：

原始数据 → 数据处理 → 模型建立 → 求解或预测 → 评价与验证 → 结果展示

# 模块 1：01_Data_Analysis 数据分析

用于建模前的数据检查、尺度统一、相关性探索和基础可视化。

## 方法选择

| 方法 | 适用场景 | 特点 |
|---|---|---|
| 数据清洗 | 原始数据有缺失或重复 | 支持缺失统计、均值/中位数填充、去重 |
| Min-Max | 需要统一到 0～1 | 适合综合评价和距离计算 |
| Z-score | 特征量纲差异明显 | 适合机器学习、聚类和 PCA |
| 正负向归一化 | 评价指标方向不同 | 将“越大越好”和“越小越好”统一 |
| Pearson | 连续变量线性关系 | 输出相关系数矩阵 |
| Spearman | 非正态或秩单调关系 | 对变量具体分布要求较低 |
| 基础绘图 | 数据探索和结果展示 | 直接显示图形 |

## 文件说明

| 文件 | 功能 |
|---|---|
| correlation.py | 计算 Pearson 和 Spearman 相关系数矩阵 |
| data_clean.py | 缺失检查、数值填充、去重、描述统计 |
| data_read.py | 当前与 data_clean.py 重复，不负责读取文件 |
| normalization.py | Min-Max、Z-score、正负向指标归一化 |
| visualization.py | 直方图、箱线图、散点图、折线图、热力图、预测对比图 |

# 模块 2：02_Prediction 预测模型

用于时间序列外推和根据多个特征预测连续目标。

## 方法选择

| 方法 | 适用场景 | 特点 |
|---|---|---|
| ARIMA | 单变量时间序列、自相关明显 | 需要自行选择 p、d、q |
| GM(1,1) | 少量、趋势较稳定的数据 | 当前实现不完整，正式使用前需修正 |
| 线性回归 | 特征与目标近似线性 | 适合作为可解释基线 |
| 多项式回归 | 低维曲线关系 | 阶数过高容易过拟合 |
| 随机森林 | 表格数据、非线性和特征交互 | 可输出特征重要性 |
| XGBoost | 复杂表格数据回归 | 效果依赖参数设置 |
| LSTM | 序列深度学习 | 当前仅提供网络结构 |

## 文件说明

| 文件 | 功能 |
|---|---|
| ARIMA.py | ARIMA 拟合、未来预测和模型摘要 |
| GreyPrediction.py | GM(1,1) 参数估计与指数序列计算 |
| LinearRegression.py | 线性回归训练、预测、MSE 和 R² |
| PolynomialRegression.py | 多项式特征回归、预测和评价 |
| RandomForest.py | 随机森林回归和特征重要性 |
| XGBoost.py | XGBoost 回归和特征重要性 |
| LSTM.py | PyTorch LSTM 与全连接输出层 |

> 回归模型需要自行划分训练集和测试集；当前不提供交叉验证或自动调参。LSTM 还需要自行编写数据窗口、损失函数和训练流程。

# 模块 3：03_Optimization 优化与规划

用于在目标函数和约束条件下寻找最优决策方案。

## 方法选择

| 方法 | 适用场景 | 特点 |
|---|---|---|
| 线性规划 | 连续变量、线性目标和约束 | 优先用于结构明确的线性问题 |
| 整数规划 | 决策数量必须是整数 | 适合人员、设备、批次分配 |
| 0-1 规划 | 选或不选 | 适合选址和项目组合 |
| SLSQP | 光滑非线性约束问题 | 局部最小化，依赖初值 |
| 遗传算法 | 黑箱、非凸、多峰问题 | 连续变量随机最大化 |
| 模拟退火 | 黑箱连续优化 | 通过概率接受较差解跳出局部最优 |

## 文件说明

| 文件 | 功能 |
|---|---|
| LinearProgramming.py | SciPy 线性规划，支持最小化或最大化 |
| IntegerProgramming.py | PuLP 非负整数规划 |
| ZeroOneProgramming.py | PuLP 二元规划 |
| NonlinearOptimization.py | SLSQP 非线性最小化 |
| GeneticAlgorithm.py | 选择、交叉、变异的遗传算法 |
| SimulatedAnnealing.py | 连续变量模拟退火最大化 |

> 能准确写出线性目标和约束时，优先使用规划模型；启发式算法适合求近似解，应多次运行检查稳定性。

# 模块 4：04_Evaluation 综合评价

用于指标赋权、方案评分、排序和等级判定。

## 方法选择

| 方法 | 适用场景 | 特点 |
|---|---|---|
| AHP | 有专家判断和层次结构 | 主观赋权，包含一致性比率 |
| 熵权法 | 希望由样本差异决定权重 | 客观赋权，需先统一指标方向 |
| TOPSIS | 多方案、多指标综合排序 | 比较方案与正负理想解的距离 |
| 模糊综合评价 | 结果按等级划分 | 需要预先构造隶属度矩阵 |

## 文件说明

| 文件 | 功能 |
|---|---|
| AHP.py | 特征向量法求权重并计算一致性比率 |
| EntropyWeight.py | 极差标准化和熵权计算 |
| TOPSIS.py | 加权 TOPSIS 综合得分 |
| FuzzyEvaluation.py | 权重与隶属度合成、最大隶属度判级 |

> 常见流程：指标正向化 → AHP 或熵权法确定权重 → TOPSIS 评分排序。权重来源和指标方向应在论文中说明。

## 方法选择

| 方法 | 适用场景 | 特点 |

| 文件 | 功能 |

## 4. 模型选择建议

- 先判断题目属于预测、评价、优化、分类、机理还是数值计算，不要先选算法再套题。
- 时间序列只有历史值时优先考虑 ARIMA；存在多个解释变量时考虑回归、随机森林或 XGBoost。
- 关系清晰且需要解释时优先选择线性回归、规划模型或机理方程。
- 综合评价先统一指标方向，再决定主观赋权、客观赋权或组合赋权。
- 结构明确的优化问题优先使用线性、整数或 0-1 规划；黑箱问题再使用启发式算法。
- 至少准备一个简单基线模型，并使用独立测试数据或合理的验证方案比较模型。
- 模型复杂度应与数据量、比赛时间和论文解释能力匹配。

## 5. 比赛使用流程

1. 明确任务：识别题目要求的是预测、评价、优化、分类还是机理分析。
2. 检查数据：处理缺失、重复、量纲和指标方向，绘图观察基本规律。
3. 建立基线：先选择结构简单、容易解释的模型。
4. 选择改进模型：根据非线性、约束、时序性或高维特征升级模型。
5. 验证结果：划分训练与测试数据，计算误差或比较方案排序。
6. 稳健性检查：改变关键参数、权重或随机种子，观察结论是否稳定。
7. 形成论文结果：保留模型假设、参数来源、评价指标和关键图表。
